# HumanitZ — интерактивная установка на сервер

Проект заменён комплектом для обычного VPS/VDS с SSH. Установщик подготавливает
Docker, спрашивает настройки и автоматически разворачивает игровой сервер.
Прежняя конфигурация Timeweb App Platform больше не используется.

## Требования

Ubuntu 24.04 LTS, x86_64, root или sudo, публичный IP, минимум 4 ГБ RAM,
рекомендуется 8 ГБ; минимум 10 ГБ свободного места для первоначальной установки.
Нужен доступ к репозиториям Ubuntu, Docker Hub, GitHub и Steam.
Сервер с 1 ГБ RAM для этой установки не подходит; установщик остановится до изменений.

## Установка

На сервере по SSH выполните:

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/open-licence/HUMANITZ-DOCKER.git
cd HUMANITZ-DOCKER
sudo bash install.sh
```

Установщик спросит имя сервера, пароль администратора и пароль игроков.
Для администратора можно нажать Enter — будет создан случайный пароль.
Пустой пароль игроков означает открытый сервер. Перед изменениями скрипт
покажет параметры и запросит подтверждение.

Docker устанавливается из официального apt-репозитория. Готовый Docker с
Compose v2 используется без переустановки. При конфликтующих пакетах скрипт
останавливается, не удаляя их. Файлы развёртывания копируются в `/opt/humanitz`.
Первый запуск автоматически скачивает HumanitZ через SteamCMD.

В облачном firewall разрешите UDP **7777** и **27015**. Установщик не меняет
SSH и правила firewall. Docker публикует порты на всех интерфейсах; его
публикация портов может обходить правила UFW — ограничивайте доступ также
облачным firewall. Дождитесь готовности игры в логах, а не только запуска контейнера.

## Подключение и администратор

В HumanitZ откройте сетевую игру и подключитесь по адресу `ПУБЛИЧНЫЙ_IP:7777`
или найдите сервер по заданному имени. Если включён пароль игроков, используйте его.

Отдельного пользователя admin нет: вы входите своим Steam-пользователем.
Для прав администратора введите в игровом чате `/AdminAccess ВАШ_ПАРОЛЬ`.
Установщик покажет эту команду после запуска. `/adminw` открывает игровой
административный интерфейс, `/SaveGame` сохраняет игру.

Пароли хранятся только на вашем сервере в `/opt/humanitz/.env`, доступном root.
Они не включены в GitHub. Не публикуйте этот файл или вывод `docker compose config`
без флага `--quiet`, поскольку там могут отображаться секреты.

## Управление

Команды на сервере:

```bash
cd /opt/humanitz
sudo docker compose ps
sudo docker compose logs -f --tail 100
sudo docker compose restart
sudo docker compose stop
sudo docker compose up -d
```

Ctrl+C прекращает просмотр логов. Контейнер остаётся работать.
Docker включён в автозагрузку; сервер перезапускается после перезагрузки машины,
если вы не остановили его вручную. Игра проверяет обновления при запуске и
каждые 30 минут; обновление может прервать игру.

Для изменения имени/паролей повторите `sudo bash install.sh` из скачанного
репозитория и подтвердите перенастройку. Мир сохраняется, старый `.env`
копируется в `.env.backup.ДАТА`. Повторная установка требует ввести все параметры.
Чтобы получить обновления скриптов: выполните `git pull --ff-only` в клоне
репозитория, затем запустите установщик ещё раз.

## Сохранения и резервная копия

Весь `/data` находится в постоянном Docker-томе **humanitz-data**.
Обновление образа и пересоздание контейнера сохраняют мир. `docker compose down`
не удаляет том, но **`docker compose down -v` удалит его**.
Удаление облачного сервера также может уничтожить данные.

Пример резервного копирования с остановкой сервера (выполняйте от root):

```bash
cd /opt/humanitz
docker compose stop
mkdir -p /root/humanitz-backups
docker run --rm -v humanitz-data:/data:ro -v /root/humanitz-backups:/backup ubuntu:24.04 \
  tar -czf /backup/humanitz-$(date +%Y%m%d-%H%M%S).tar.gz -C /data .
docker compose up -d
```

Перенесите копию на другой диск или в хранилище. Архив содержит весь том,
включая игровые настройки и пароль администратора. Автоматическое резервное
копирование в этом комплекте не настроено.

## Состав и проверка

- `install.sh` — интерактивная первоначальная установка и перенастройка.
- `docker-compose.yml` — контейнер, порты и постоянный том.
- `humanitz/` — Dockerfile и скрипты проверки/применения настроек перед запуском.
- `.gitignore` — исключение локальных паролей; `.gitattributes` — окончания строк LF.

Проверки Bash и применения конфигурации выполняются локально. Полная установка
на Ubuntu и подключение игрока в этой среде не проверены: Linux-сервера и Docker
для интеграционной проверки нет.

Источники: [Docker на Ubuntu](https://docs.docker.com/engine/install/ubuntu/),
[LinuxGSM HumanitZ](https://linuxgsm.com/servers/hzserver/),
[настройки HumanitZ](https://humanitz.wiki.gg/wiki/Server_Configuration_Files).
